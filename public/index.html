Nombre descriptivo para identificar la terminal en el sistema.
ℹ️ El Terminal ID identifica tu dispositivo Point en la API de Mercado Pago. Puedes obtenerlo de tres formas:

¿Cómo obtener el Terminal ID?

  • 1 Desde la app MP: Abre Mercado Pago → Cobrar con Point → selecciona tu dispositivo → Ajustes → ID del dispositivo.
  • 2 Botón de consulta: Cierra este modal y pulsa "Ver terminales en mi cuenta MP" para obtenerlos automáticamente.
  • 3 Panel de desarrolladores: Consulta api.mercadopago.com/terminals/v1/list con tu Access Token.
